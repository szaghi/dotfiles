# Glossary — darktable 4.6 RAW Processing

**AMaZE** — demosaic algorithm, best high-frequency detail, slow, color-overshoot-prone (Ch 5)
**area exposure mapping** — exposure-module feature to batch-match brightness across a series via a control sample (Ch 2)
**Bayer array** — color-filter mosaic; each photosite records one of R/G/B (Ch 5)
**base curve** — legacy display-referred tone mapper; replaced by filmic/sigmoid (Ch 1, 12)
**blending** — combining a module's input and output via a blend mode + opacity (Ch 6)
**CAT** — Chromatic Adaptation Transformation; full WB in color calibration (Ch 3)
**CAT16** — default chromatic-adaptation color space (Ch 3)
**CCT** — correlated color temperature; meaningful only near daylight/black-body spectra (Ch 3)
**clipping** — pixel exceeds sensor/RAW capacity; color/luminance info lost (Ch 4)
**color assessment mode** — `Ctrl+B`; white frame on grey for honest tone judging (Ch 1)
**color calibration** — CAT white balance + channel mixer; primary color-grading (Ch 3)
**color balance rgb** — secondary creative color-grading (4-ways, chroma, vibrance) (Ch 3)
**darktable-cli** — headless export binary (Ch 10)
**demosaic** — reconstructs full RGB from the Bayer mosaic (Ch 5)
**denoise (profiled)** — camera-noise-profiled denoiser, wavelets (default) / non-local means (Ch 5)
**diffuse or sharpen** — physics-based diffusion model (deblur/dehaze/sharpen/acutance) (Ch 5)
**display-referred** — legacy workflow; early irreversible tone curve; deprecated default (Ch 1)
**.dtstyle** — XML style file; carries packed params; GUI-authored (Ch 10)
**eigf** — exposure-independent guided filter; tone-equalizer default mask smoothing (Ch 2)
**ETTR** — Expose To The Right; max exposure without clipping (Ch 2)
**filmic rgb** — primary display transform; maps scene DR to display (Ch 2)
**guided laplacians** — highlight-reconstruction method for spotlights/specular (Bayer) (Ch 4)
**highlight reconstruction** — pre-demosaic recovery of clipped channels (Ch 4)
**history stack** — ordered record of edits; stored in library DB + XMP sidecar (Ch 1, 10)
**inpaint opposed** — default highlight-reconstruction method (Ch 4)
**iop_order** — module execution order; v3.0 (scene-referred) / legacy (Ch 1)
**JzAzBz** — perceptual color space used by color balance rgb saturation/brilliance (Ch 3)
**lensfun** — external lens-correction profile library (Ch 7)
**LMMSE** — demosaic algorithm best for high-ISO/moiré (Ch 5)
**local contrast** — Lab-L local-contrast enhancer; recovers filmic compression (Ch 2, 5)
**mask** — per-pixel opacity: drawn / parametric / raster (Ch 6)
**mid-gray** — scene reference luminance mapped to 18% display by filmic (Ch 2)
**parametric mask** — opacity from pixel values in a channel (Ch 6)
**pixelpipe** — ordered module sequence; executes bottom→top of UI list (Ch 1)
**preserve chrominance** — filmic option keeping color stable through tone mapping (Ch 2)
**raster mask** — reuse a mask generated by an earlier module (Ch 6)
**RCD** — default demosaic algorithm (Ch 5)
**Rec 2020** — default pipeline working color space (Ch 11)
**reconstruct color** — highlight method transferring neighbor color; good for skin (Ch 4)
**retouch** — frequency-separation heal/clone (Ch 8)
**scene-referred** — default workflow; linear unbounded data, late tone mapping (Ch 1)
**sidecar (XMP)** — `<file>.NEF.xmp`; the history stack as data; params packed (Ch 1, 10)
**sigmoid** — alternative display transform; log-logistic; skew=0 for portraits (Ch 2)
**skew** — sigmoid control shifting contrast shadows↔highlights; harsh on skin if >0 (Ch 2)
**style** — saved history stack applied via GUI or `--style` (Ch 9, 10)
**tiling** — memory-saving image split; up to 10× slower (Ch 11)
**tone equalizer** — masked dodge/burn preserving local contrast (Ch 2)
**white balance module** — technical pre-step feeding CAT; normally untouched (Ch 3)
**working space** — pipeline color space (Rec 2020 default) (Ch 11)
